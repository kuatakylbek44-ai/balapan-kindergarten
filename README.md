# Балапан

*A bilingual kindergarten website built with HTML, CSS and JavaScript.*

«Балапан» — қазақ және орыс тілдеріндегі балабақша сайтының таныстырылым нұсқасы. Сайт телефонға және компьютерге бейімделген. Үйірмелер, күн тәртібі, сүзгісі бар фотогалерея, құжаттар, жиі қойылатын сұрақтар және байланыс бөлімдері бар.

Бұл — қарапайым статикалық сайт. Оны іске қосу үшін npm, фреймворк немесе құрастыру қадамы қажет емес.

## Жергілікті іске қосу

Жобаны жүктеп, `dist/index.html` файлын браузерде ашыңыз. Кодты Visual Studio Code немесе кез келген мәтіндік редакторда өзгертуге болады.

Python орнатылған болса, жоба бумасында жергілікті серверді іске қосуға болады:

```bash
python -m http.server 4173 --directory dist
```

Браузерде [http://localhost:4173](http://localhost:4173) мекенжайын ашыңыз. Серверді тоқтату үшін терминалда `Ctrl+C` басыңыз.

## Мазмұнды өзгерту

Негізгі баптаулар `dist/content.js` файлында орналасқан:

- `SITE_CONFIG` — атау, телефон, WhatsApp нөмірі, электрондық пошта, мекенжай және құжат сілтемелері.
- `SITE_CONTENT.kk` және `SITE_CONTENT.ru` — интерфейс пен бөлім мәтіндерінің аудармалары.
- `SITE_DATA` — күн тәртібі, үйірмелердің мазмұны және галерея суреттері.

WhatsApp нөмірін ел кодымен, тек цифрлар арқылы енгізіңіз. Құжаттардың PDF файлдарын, мысалы, `dist/assets/documents/` бумасына салып, `SITE_CONFIG.documents` ішінде `assets/documents/rules.pdf` сияқты салыстырмалы жол көрсетіңіз. Әзірге қосылмаған құжаттардың мәнін `null` күйінде қалдырыңыз.

Суреттерді `dist/assets/` бумасында ауыстырыңыз. Галереяның файл жолдары, атаулары және екі тілдегі балама мәтіндері `SITE_DATA.gallery` ішінде берілген. Басты бет пен «Біз туралы» бөліміндегі суреттер `dist/index.html` файлында көрсетілген.

«Танысуға жазылу» формасы хабарламаның алдын ала көрінісін дайындайды. Нақты WhatsApp нөмірі бапталмаған кезде мәліметтер ешқайда жіберілмейді. Нөмір қосылғанда пайдаланушы дайын хабарламаны жеке батырма арқылы WhatsApp-та аша алады және жіберуді сол жерде өзі орындайды. Сайт өтінім мәліметтерін серверде немесе браузердің тұрақты жадында сақтамайды; браузерде тек таңдалған тіл есте қалуы мүмкін.

## Файлдар

```text
dist/
  index.html       Бет құрылымы
  styles.css       Дизайн және бейімделетін орналасу
  script.js        Тілдер, мәзір, галерея, диалогтар және форма
  content.js       Мәтіндер, аудармалар және баптаулар
  assets/          Суреттер, қаріптер, фавикон және лицензиялар
THIRD-PARTY-NOTICES.txt
```

Сайтты жариялау үшін `dist/` бумасының **ішіндегі файлдарды** статикалық хостингке орналастырыңыз. `index.html` жарияланатын түбірде болуы керек. Доменді қосу таңдалған хостингтің баптаулары арқылы орындалады.

## GitHub Pages арқылы жариялау

Бастапқы код `main` тармағында сақталады. GitHub Pages үшін `dist/` ішіндегі сайт файлдары `gh-pages` тармағының түбіріне шығарылады. Репозиторийдегі **Settings → Pages** баптауы: **Deploy from a branch → gh-pages → / (root)**.

Өзгерістерді `main` тармағына commit жасап, GitHub-қа жүктегеннен кейін сайтты жаңарту:

```bash
git subtree split --prefix dist -b pages-release
git push origin pages-release:gh-pages
```

`pages-release` бұрыннан бар болса, келесі жаңартуға басқа жергілікті тармақ атауын қолданыңыз. Сайтта жиналу қадамы жоқ; `.nojekyll` GitHub-қа дайын статикалық файлдарды беру үшін қосылған. Жариялау күйін репозиторийдің **Actions** немесе **Settings → Pages** бөлімінен тексеріңіз.
